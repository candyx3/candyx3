## 👨‍💻 About Me

I'm Chandru, a cybersecurity enthusiast and developer interested in understanding how systems work, identifying security weaknesses, and building useful applications.

My interests span both offensive and defensive security, along with software development.

- 🔐 **VAPT:** Learning vulnerability assessment and penetration-testing techniques in authorized environments.
- 🛡️ **SOC Analysis:** Exploring security monitoring, log analysis, threat detection, and incident response.
- 🐧 **Linux:** Practicing Linux commands, system administration, and security fundamentals.
- 💻 **Development:** Building web applications and experimenting with AI-powered tools.
- 🧪 **Hands-on Learning:** Improving through personal projects, practical labs, and continuous experimentation.
